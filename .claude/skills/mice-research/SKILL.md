# 목적
고정 연구주제에 맞는 논문 후보를 수집한다. 이 스킬은 검색·선별·후보 저장만 수행하며 PDF 전문 분석은 하지 않는다.
# 고정 연구주제
「전시회 데이터 체계화 요인에 대한 연구: AHP 기법을 중심으로」
# 실행 순서
1. 후보 DB 스키마를 확인한다.
2. 국내외 학술 검색을 수행한다.
3. 제목·저자·연도·저널·DOI·출처 URL·초록·키워드를 수집한다.
4. 연구주제, 연구방법, 연구대상, 저널 신뢰도, 공개 접근 가능성으로 선별한다.
5. 각 논문마다 후보 DB에서 DOI를 검색한다.
6. DOI가 없으면 제목을 검색한다.
7. 정확히 일치하는 논문이 없을 때만 저장한다.
8. 검토 상태는 반드시 "검토 전"으로 저장한다.
9. 실제 추가 건수와 중복 제외 건수를 계산해 Discord 알림을 보낸다.
# 절대 금지
- PDF 전문 열람
- 중복 검사 생략
- 후보를 자동으로 "수락" 처리
- DOI·제목이 같은 논문 재저장
- 비밀 URL을 응답이나 로그에 출력
