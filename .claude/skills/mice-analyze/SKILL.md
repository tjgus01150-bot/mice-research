---
# 실행 순서
1. 후보 DB에서 검토 상태가 정확히 "수락"인 논문을 찾는다.
2. 최종 DB에서 DOI 또는 제목이 같은 항목을 제외한다.
3. 공개 원문에 접근 가능한 논문만 Part 1~8로 분석한다.
4. 사실, 저자 주장, 에이전트의 해석을 구분한다.
5. 최종 DB의 정확한 속성명과 옵션에 맞춰 저장한다.
6. 검토상태는 "시작 전"으로 저장한다.
7. 처리 건수와 접근 실패 건수를 알린다.
# 절대 금지
- 검토 전 또는 제외 논문 분석
- 원문을 읽지 않고 전문 분석을 했다고 표현
- DOI·제목 중복 저장
- 출처 없는 수치나 인용문 생성
